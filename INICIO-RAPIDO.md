# 🚀 INICIO RÁPIDO — Dashboard Bolsa

## 📱 PARA USAR EN TU PC (3 pasos)

### Paso 1: Instalar Python
Si no lo tienes: https://www.python.org/downloads/
Descargar e instalar (marcar "Add to PATH").

### Paso 2: Abrir terminal en la carpeta
Ubicarte en la carpeta `bolsa-dashboard` y abrir CMD/Terminal ahí.

### Paso 3: Ejecutar
```bash
pip install -r requirements.txt
streamlit run app.py
```

Se abre automáticamente en: `http://localhost:8501`

## 🚨 IMPORTANTE

Los datos NO se guardan automáticamente. 

**SIEMPRE hacer backup después de agregar datos:**
1. Ir a ⚙️ Configuración
2. Click "💾 Exportar TODO"
3. Guardar JSON

Para restaurar: Subir el JSON en "📂 Restaurar backup"
